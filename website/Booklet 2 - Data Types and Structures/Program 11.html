Technical Explanation

This program demonstrates inheritance and polymorphism using `Event` as a parent class and `WorkMeeting` and `Personal` as child classes. A fixed-size array stores mixed object types, then shared method calls show polymorphic behavior. `WorkMeeting` overrides `getDate()`, so the same method call gives different output depending on object type.

Design

Parent class: Event Child classes: WorkMeeting, Personal This program demonstrates polymorphism. A fixed-size array stores objects of different types — Event, WorkMeeting, and Personal. Calling the same method on each object gives different results because WorkMeeting overrides getDate(). The Personal class inherits from Event and adds its own properties and getter/setter methods.

### Array of Objects Design (Plain English) - The program prepares one fixed list of event spaces. - Each space can hold a general event or a specialised event type. - As objects are created, they are placed in order from the first free space onward. - The list keeps object order predictable, so tests can target specific positions. - During output, the program checks each object and uses behavior that matches its type. ### English Pseudocode Parent Constructor: Event() 1. Accept the starting date, time, venue and reminder values. 2. Store each value inside the event object. 3. Create an empty participants list. 4. Set the participant index to the first free position. Parent Method: updateDate() 1. Accept a new date value. 2. Replace the current stored date with the new date. Parent Method: getDate() 1. Read the stored date from the object. 2. Return that date value. Parent Method: getVenue() 1. Read the venue stored in the object. 2. Return that venue value. Parent Method: getParticipants() 1. Read the participants list stored in the object. 2. Return the full participants list. Parent Method: addParticipant() 1. Accept a participant name. 2. Store the name in the participants list at the next free position. 3. Increase the index so the next participant is stored in the next space. WorkMeeting Constructor: WorkMeeting() 1. Accept all the event details plus the meeting title and mileage. 2. Call the parent constructor to set up the inherited event data. 3. Store the meeting title and mileage in the child object. 4. Set the initial travel expenses to zero. WorkMeeting Method: getDate() (overrides parent) 1. Call the parent version of getDate(). 2. Add text that makes the message specific to a work meeting. 3. Return the new combined string. WorkMeeting Method: calculateTravelExpenses() 1. Read the mileage stored in the child object. 2. Multiply the mileage by 1.5. 3. Store the result as the travel expenses. WorkMeeting Method: getTravelExpenses() 1. Read the stored travel expenses. 2. Return that value. Personal Constructor: Personal() 1. Accept all the event details plus the event type and description. 2. Call the parent constructor to set up the inherited event data. 3. Store the event type and description in the child object. Personal Method: setEventType() 1. Accept a new event type value. 2. Replace the current stored event type with the new value. Personal Method: setDescription() 1. Accept a new description value. 2. Replace the current stored description with the new value. Personal Method: getEventType() 1. Read the event type stored in the child object. 2. Return that value. Personal Method: getDescription() 1. Read the description stored in the child object. 2. Return that value. ---

Python Code
class Event:
    def __init__(self, startDate, startTime, venue, reminder):
        self.startDate = str(startDate)  #String
        self.startTime = str(startTime)  #String
        self.venue = str(venue)          #String
        self.reminder = reminder if isinstance(reminder, bool) else str(reminder).strip().lower() in ("true", "1", "yes", "y")    #Boolean (don't use bool(reminder): bool("False") is True)
        self.participants = [""]*20 #Array of String
        self.index = int(0)              #Integer

    def updateDate(self, eventDate):
        self.startDate  = str(eventDate)

    def getDate(self):
        return self.startDate

    def getParticipants(self):
        return self.participants

    def addParticipant(self, name):
        self.participants[self.index] = str(name)
        self.index = self.index + 1

class WorkMeeting(Event):
    def __init__(self, startDate, startTime, venue, reminder, meetingTitle, mileage ):
        super().__init__(startDate, startTime, venue, reminder)
        self.meetingTitle = str(meetingTitle)      #String
        self.mileage = float(mileage)                #Real
        self.travelExpenses = float(0)               #Real

    def calculateTravelExpenses(self):
        self.travelExpenses = self.mileage * 1.5
    
    def getTravelExpenses(self):
        return self.travelExpenses

    def getDate(self):
        return ("The date of this Work Meeting is " + super().getDate())

class Personal(Event):
    def __init__(self, startDate, startTime, venue, reminder, eventType, description):
        super().__init__(startDate, startTime, venue, reminder)
        self.eventType = str(eventType)      # String
        self.description = str(description)  # String

    def setEventType(self, eventType):
        self.eventType = str(eventType)

    def setDescription(self, description):
        self.description = str(description)

    def getEventType(self):
        return self.eventType

    def getDescription(self):
        return self.description

# 1) instantiate objects of each class (top-level demo, runs without using __name__ guard)
e = Event("2026-04-23", "09:00", "Library", False)
w = WorkMeeting("2026-04-24", "10:00", "Office", True, "Budget Meeting", 12.0)
p = Personal("2026-04-25", "18:00", "Home", False, "Birthday", "Dinner with family")

# prepare list (array) of objects
events = [e, w, p]

# WorkMeeting overrides getDate(); all classes inherit addParticipant from Event
print("--- Call getDate() (shows override in WorkMeeting) and addParticipant (inherited) ---")
for obj in events:
    print("getDate():", obj.getDate())
    obj.addParticipant("Alice")
    print("  first participant stored:", obj.getParticipants()[0])

# Demonstrate that subclass-only methods/properties must be accessed carefully.
print("
--- Attempt to call WorkMeeting-only method getTravelExpenses() on every item (runtime check) ---")
# calculate travel expenses for the WorkMeeting instance so it has a value
w.calculateTravelExpenses()
for obj in events:
    if isinstance(obj, WorkMeeting):
        print("getTravelExpenses():", obj.getTravelExpenses())
    else:
        print("getTravelExpenses(): not available for", type(obj).__name__)

print("
--- Access Personal-specific properties/methods using isinstance (safe) ---")
for obj in events:
    if isinstance(obj, Personal):
        print("Personal eventType:", obj.getEventType())
        print("Personal description:", obj.getDescription())
